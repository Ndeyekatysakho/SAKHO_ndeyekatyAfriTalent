                                                  AfriTalent 

📌 Présentation du projet

AfriTalent est un site web conçu pour mettre en avant les talents africains, faciliter la découverte de profils et présenter une plateforme moderne dédiée au développement des compétences.

Ce projet a été réalisé dans le cadre d’un projet de développement web avec l’objectif de créer une interface simple, moderne, responsive et agréable à utiliser sur ordinateur, tablette et mobile.
Objectifs du projet
<!-- OBJECTIF DU PROJET -->
Les objectifs principaux du site sont :

 Présenter le concept d’AfriTalent
 Mettre en valeur les talents et compétences
 Proposer une navigation claire pour les utilisateurs
 Créer une expérience utilisateur moderne grâce aux animations
 Adapter le site à différents formats d’écran (responsive design)

Barre de navigation
 Sections de présentation
 Cartes de contenu

Couleurs et thèmes

 Les composants comme les boutons, cartes et accordéons

Palette de couleurs
Le design utilise une palette moderne inspirée de l’identité africaine et du numérique.

Exemples de couleurs utilisées :

 Couleurs secondaires : pour apporter une identité visuelle dynamique* Couleurs neutres : pour améliorer la lisibilité

 Garder une interface simple et moderne

Fonctionnalités du site

Navigation

 Aux ordinateurs
 Aux tablettes
Aux smartphones

Animations

 Effets au survol
 Transitions
